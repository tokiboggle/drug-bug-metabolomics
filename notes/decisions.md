| 2026-11-26 | **Remove 4 failed bacterial injections** (`T4_DMSO_Bac_rep3`, `T4_Omepr_Bac_rep3`, `T5_DMSO_Bac_rep3`, `T5_Omepr_Bac_rep2`), retaining `n = 50` valid bacterial samples | All 4 had TIC `4.4–4.7 × 10⁷` (lower than all 4 solvent blanks, `6.4–9.0 × 10⁷`), `>81%` zeros, and correlated `r = 0.83–0.89` with Blanks vs `r = 0.21–0.40` with true replicates; 3 occurred back-to-back on `2024-07-04 00:09–00:38`. Leaving them in severely distorts T4/T5 means, normalization, PCA, and ANOVA. |
| 2026-11-26 | **Do NOT use Pooled QC presence/RSD as a hard inclusion filter**; use Blanks (`max group mean > 3× mean Blank`) + replicate prevalence (`≥ 2` reps in `≥ 1` `Treatment × Time` group) | This table (`4,525` features, `row ID` 16–11,816) is a subset of the 12-drug Com20 study (Pakkir Shah et al., 2026). Pooled QCs were pooled across all 12 drugs (even containing `erythromycin`, `ID 4135`), diluting Omeprazole-only features ~12× so `629/1,060` Omeprazole-specific features are absent from Pooled QCs. Filtering on prevalence + `>3×` Blank retains `3,414` high-confidence features (`1,814` IIMN-collapsed unique entities). `QC-Mix` is an in-house 6-compound synthetic standard mix (sulfonamides/amitriptyline) used only for RT/mass stability, not biological filtering. |
| 2026-11-26 | **Use Probabilistic Quotient Normalization (PQN)** anchored to `1,902` ubiquitous DMSO features instead of Total Ion Current (TIC) normalization | Ufiprazole (`ID 2962`) and its 9 co-eluting IIMN fragments/isotopes (`cg=220`) surge 9-fold from T0→T8, reaching ~47% of total TIC and doubling late Omeprazole TIC (`1.05× → 1.99×`). Blind TIC normalization falsely pushes down `1,780/2,146` (`83%`) shared endogenous features (`1,387` fake negative `Trt × Time` hits). PQN stays flat (`0.84–1.05×`) and removes this compositional bias. |
| 2026-11-26 | **Impute left-censored zeros with `0.2 × min(positive)` per feature and `log₂`-transform** | Standard MetaboAnalyst left-censored LOD imputation stabilizes variance and prevents `-inf` values in linear models, ANOVA, PCA, and ML while preserving fold-change order. |
| 2026-11-26 | **Explicitly model and adjust for LC-MS acquisition order (`run_date` / `run_hours`)** | Sampling timepoint is partially confounded with LC-MS injection order over the 5.3-day queue (`r = -0.474, p = 0.017` in DMSO; `r = -0.427, p = 0.033` in Omeprazole). Acid-labile parent Omeprazole (`ID 2828`) decays strongly with queue time (`r = -0.620, p = 0.0009`), dropping to `0` in T1 and T2 (injected last on Day 5–6). Adding `run_hours` as a covariate in linear models and testing conditional PERMANOVA (`R² ≤ 1.1%, p > 0.06`) isolates genuine biological trajectories from queue drift. |
| 2026-11-26 | **Flag `RT 1.80–2.25 min` as an ESI co-elution ion-suppression zone** when interpreting endogenous depletions | `114/172` (`66.3%`) of significant negative `Treatment × Time` shared endogenous interactions fall inside `RT 1.80–2.25 min` (only `9.0%` of shared features; `OR = 46.5`, Fisher `p = 2.12 × 10⁻⁹¹`), directly co-eluting with the overloaded `4.9 × 10⁸` Ufiprazole peak (`RT = 1.90 min`). Features inside this window (e.g., `N-Phenethylacetamide ID 2972`, `IPA isomer ID 3178`) are flagged as matrix-suppression artifacts rather than biological depletion. |
| 2026-11-26 | **Combine Run-Adjusted Linear Modeling, Two-Way Categorical ANOVA, Within-Omeprazole Spearman/ANOVA, and Permutation PERMANOVA (`999` perms), all BH-FDR corrected (`q < 0.05`)** | Linear models test directional slopes while controlling for `run_hours`; Categorical ANOVA catches `+774` non-linear/transient intermediates (e.g., `ID 4470`, `ID 2719` peaking at T3 then depleting by T8); within-Omeprazole tests avoid `log₂` trace-carryover distortion on Ufiprazole (`ID 2962`, where `0.01%` DMSO carryover fluctuations cancel the `log₂` interaction term despite a 6,100× treatment ratio and `r_time = +0.976`). |
| 2026-11-26 | **Collapse IIMN `correlation group ID` ions into unique molecular entities (`1,814`)** before kinetic clustering, ML ranking, and biotransformation networking | Prevents a single hyper-abundant compound (e.g., Ufiprazole spawning 10 features in `cg=220`) from dominating cluster counts, ML importance, or network degree. |
| 2026-11-26 | **Audit all 259 kept MS2 annotations before chemical-class enrichment (ORA)** | Separates genuine biological/omeprazole hits from trace carryover of 10 other study drugs + 6 QC-Mix standards, and flags `ID 5664` (`Sertindole`) as a false spectral match because it completely lacks the mandatory `32% ³⁷Cl` M+2 isotope peak. Uses measured non-carryover annotations (`n = 228`) as the Fisher's exact background (matching Week 7 best practices). |
| 2026-11-26 | **Use RDKit 2D structures, Morgan Tanimoto similarity, high-resolution exact-mass formulas (`< 5 ppm`), `³⁴S` M+2 isotope ratios, and co-eluting in-source fragments for Step 7 hit zoom-in** | Provides orthogonal physical-chemistry verification for both annotated hits (`Ufiprazole ID 2962`, `5-MeO-2-MBI ID 2480`, `Omeprazole 4-desmethylthioether ID 2465`) and top dark-metabolome candidates (`ID 3605`/`ID 2500` regioisomeric methyl-ufiprazoles, `ID 2368 C₁₁H₁₅NO₃S₂` verified 2S + intact pyridine `151.0992`). |
